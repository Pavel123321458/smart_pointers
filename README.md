# Лабораторная работа: Умные указатели (Smart Pointers)

## Описание

Реализация идиомы «умный указатель» для автоматического управления памятью в C++.

## Реализованные классы

### `UnqPtr<T>` — уникальное владение

Аналог `std::unique_ptr`. Указатель с **исключительным** владением.

**Особенности:**
- Копирование запрещено (`= delete`)
- Перемещение разрешено (move-семантика)
- При уничтожении вызывает `delete ptr`
- Поддержка подтипизации (наследник → база)
- Специализация `UnqPtr<T[]>` для массивов (`delete[]`)

**Методы:**
- `get()` — вернуть сырой указатель
- `release()` — отдать владение, обнулить себя
- `reset(T* p)` — заменить объект
- `operator*`, `operator->` — доступ как у обычного указателя

### `ShrdPtr<T>` — разделяемое владение

Аналог `std::shared_ptr`. Указатель с **разделяемым** владением через счётчик ссылок.

**Особенности:**
- Копирование разрешено (счётчик++)
- При уничтожении счётчик--, при 0 → `delete`
- Поддержка подтипизации
- Специализация `ShrdPtr<T[]>` для массивов

**Методы:**
- `get()`, `reset()`, `use_count()` — аналог STL
- `operator*`, `operator->`, `operator[]` (для массивов)

### `DynamicArray<T>` — контейнер на умных указателях

Динамический массив, хранящий `UnqPtr<T>`.

**Методы:**
- `Append(val)` — добавить в конец
- `Get(index)` — получить `UnqPtr<T>&`
- `Set(index, val)` — установить значение
- `GetSize()` — размер

**Особенности:**
- `ensureCapacity` — расширение с move-семантикой
- Исключения при выходе за границы
